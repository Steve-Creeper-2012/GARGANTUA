# experiments/ — 测试与对比数据预留目录

**当前为空，不填充任何具体数据**（2026-11-12 整理时建立）。

用途：后续做架构 / 词表 / 训练策略的 A-B 对比时，把可复现的原始观测数据放
在这里，避免散落到 `data/tmp/`（运行时临时目录）、`logs/`（运行日志）或
桌面。本目录只放**数据**，不放代码、不放脚本、不放模型权重。

## 约定（开始使用时再落地）

- 一个实验一个子目录：`<YYYYMMDD>-<主题>/`，例如
  `20261120-momw-threshold/`。
- 每个子目录自带一份 `README.md`，写明：目的、被测 commit hash、环境
  （OS / CPU / torch 版本）、输入数据、执行命令、指标定义。
- 原始观测用 `.json` / `.csv` / `.jsonl`；结论与图放 `report.md` / `*.svg`，
  不要把结论混进原始数据。
- 大文件（权重、视频、完整语料）不入库，只记录来源路径与哈希。
- 本目录默认进仓库；若某次实验数据过大，可在该子目录内自行加
  `.gitignore`，不要改根目录规则。

## 与相邻目录的边界

| 目录 | 放什么 | 是否进仓库 |
| --- | --- | --- |
| `experiments/` | 有意保留、可复现的对比数据 | 是（小数据） |
| `data/queue` / `data/done` | 训练队列文件 | 否 |
| `data/tmp/` | 运行时临时文件、回归日志 | 否 |
| `logs/` | server / 训练 / 推理存档日志 | 否 |
| `service/*/output/` | 各服务单次运行的产物 | 否 |
