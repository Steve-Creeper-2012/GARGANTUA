文本 → token 转换

输出为项目定制 token 时间步格式：{}=一个时间步，{}内 token 以半角逗号分隔，裸字符/数字不带符号 
—

音频 → token 转换

支持 wav / mp3 / flac / ogg（ffmpeg 解码后重采样到 16kHz 单声道）；533 个采样点平铺为一条向量 = 1 个音元（≈30 tok/s），embedding 时直接乘矩阵投影，外围裹 <audio>…<audio/>
—

图片 → token 转换（单帧）

图片拆 32×32 patches，patch 内部平铺成一条向量，embedding 时乘矩阵投影，所有 patch 放在同一个时间步内，外围裹 <visual>…<visual/>
—

视频 → token 转换（含声音）

导入视频（mp4/mov/webm/mkv/gif，ffmpeg 抽帧 30fps、提取音轨）；每帧 = patches 裹 <visual> + 该帧 533 采样音频裹 <audio>，同一帧放在同一个时间步
—

图像 → 图元转换（可视化）

上传图片，按 wonderfulearth/primitive-operation-painter 的 image-to-sequence 思路（贪心拟合矩形/椭圆+背景，残差最小化）转换为图元序列并渲染
原图
图元渲染（SVG）

MIDI → token 转换

导入 .mid / .midi（SMF），解析 note_on/note_off/velocity/program/tempo/time_shift 为离散 token，输出定制时间步格式（每 token 一个时间步）

Token 编辑器

GARGANTUA token stream（.gts）：{} 为时间步原子，<...> 为特殊/边界 token，裸字符为 char token。所有边界 token 各自独占一个时间步。同时间步多 token 仅用于图像/视频帧。
