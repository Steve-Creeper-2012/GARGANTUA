# output/ —— 这个服务的产物目录

约定（2026-11-03，steve 定）：**每个 service 都有自己的产物文件夹**，
凡是「跑一次会生成、用户可能想回头找」的东西都放这里，不要散落到项目根、
临时目录或服务自己的源码目录里。

- 目录里除本 README 外的一切都是**本地产物**，已在 `.gitignore` 里忽略；
- 可以整个删掉，服务下次运行会自己重建（不要删源码目录里别的东西）；
- 需要长期保留的产物由用户自己拷走——这里等同于「工作区」，不是归档。

当前用法：
- `prims/output/jobs/<id>/`：图元转换任务（原图 / job.json / result.json / log.txt）
- 其它服务暂时没有落盘产物，先把这个目录占住，避免以后各写各的路径。
