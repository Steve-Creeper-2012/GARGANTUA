总上下文 = 完整 + 压缩（默认 1024+3072=4096 token）。KV 分两段：完整段不压缩；压缩段是同一段内容的两份压法——CSA 检索视图（4:1）与 HCA 全局概括视图（32:1），两者都读【压缩段 + 全部完整段】（处理未压缩 KV 时就是标准 MLA）。压缩分组以时间步为原子：组内 token 数尽量等于压缩比，凑不齐取误差最小的整步组合，绝不跨步拆分。上下文长度随 config.json 固化，加载时按同一份配置重建。

文本 → token 转换

输出为项目定制 token 时间步格式：{}=一个时间步，{}内 token 以 | 分隔，裸字符/数字不带符号 
—

音频 → token 转换

支持 wav / mp3 / flac / ogg（ffmpeg 解码后重采样到 16kHz 单声道）；533 个采样点平铺为一条向量 = 1 个音元（≈30 tok/s），每个音元是一个时间步；音频 token 是投影向量（无离散 ID），存档用 .tokenvector 格式
—

图片 → token 转换（单帧）

图片拆 32×32 patches，patch 内部平铺成一条向量，embedding 时乘矩阵投影，所有 patch 放在同一个时间步内；视觉 token 是投影向量（无离散 ID），存档用 .tokenvector 格式
—

视频 → token 转换（含声音）

导入视频（mp4/mov/webm/mkv/gif，ffmpeg 抽帧 30fps、提取音轨）；每帧 = 一个时间步，该 {} 内平铺该帧全部 patch token 与该帧音频 token（全部投影到同一个 d_model）
—

图像 → 图元转换（可视化）

上传图片，转换为图元序列并渲染。优先调用 vendored 的 Rust/wgpu GPU 转换器（service/prims/fast_shape_render，照搬 wonderfulearth/primitive-operation-painter，用 sh service/prims/setup.sh 构建）；未构建时回退 CPU 贪心拟合。token 布局照搬仓库 geometrize_256_v1：每图元 9 token（cx,cy,theta,w,h,shape,r,g,b），画布 256×256。

Token 编辑器

token-5 编码（spec 第 5b 节）：{} 为时间步原子，步内元素以 | 分隔。 {text: 00001} 文本 token（有向量、进 loss）；{wave: HEX} 音频（533 采样）； {visual: HEX x: 1 y: 2} 视觉 patch（32×32，RGBA 各 10 bit）。 <00005> 是扩展系统 token（有嵌入、不进 loss），也可直接写名字如 <stop>。 { } | 本身不是 token。词表查询与增删统一在「词表」页。
